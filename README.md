# ASHFALL / アッシュフォール

Unity 6000.6.0f1、Windows、クオータービューの世紀末ハクスラ・ローグライト。感染者と放射能変異体に覆われた荒野へ出撃し、物資とレトロフューチャー兵器を回収して避難拠点へ帰還します。独自の世界・人物・装備を使用しています。

## 起動と操作

`Play.bat` または `Builds/Windows/NeonVault.exe` を起動し、「灯火基地 / 拠点へ」を選択します。保存互換のため実行ファイル名とPlayerPrefsの保存先は旧版を維持しています。Unityで編集する場合はこの正式フォルダーを開き、`Assets/Scenes/NeonVault.unity`でPlay。ランタイムに世界を生成します。再ビルドはメニュー`Ashfall > Build Windows prototype`。

| 操作 | キー |
|---|---|
| 地面の斜め軸へ移動（W:右上 / S:左下 / D:右下 / A:左上） | WASD / 矢印 |
| 照準 / 射撃 | マウス / 左クリック長押し |
| 無敵ダッシュ | Space |
| リロード | R / 空弾倉で自動 |
| 近くの銃・防具・モジュールを拾う | F |
| 拠点の生存者・出撃ゲート / 制圧した区域の出口 | E |
| 銃の切替 | ホイール / Q |
| 装備画面 | I |
| 一時停止 / 戻る | Esc |

右上で日本語・英語を切り替えられます。

## 探索と成長

「灯火基地 / LAST LIGHT」では商人と記録官を利用し、出撃ゲートで区域を選びます。死の街道Lv1–4 → 灰燼工場Lv5–8 → 汚染隔離区Lv9–12を、前の区域のクリアで段階解放。各探索は3戦闘エリアとボスエリア、計4エリアです。67×29・29×67・49×41・41×49セルの長形を含む不規則な広間と通路、敵編成、戦利品をシードから生成し、敵は地形と射線を使って追跡します。

制圧時にHP8回復、出口で3候補から現地改造を選択。現地改造は周回限定です。武器・防具・拡張モジュール、スクラップ通貨、区域の解放は保存されます。旧版の所持品ID・能力・装備を維持し、表示名と外観を新しい世界に合わせます。

物語の導入では、主人公がレイダーボスに10億スクラップの借金を負い、爆弾首輪で拘束されていることが示されます。拠点の借金取りブリッグスへ話しかけて返済し、完済すると首輪から解放されます。累計返済2,500万スクラップごとにレベルとスキルポイントを獲得。ハンドガン・ショットガン・アサルト・精密射撃の4系統、計40ノードから、威力・連射・命中・装弾数・HP・回復などを伸ばせます。

敵とチェストはスクラップ、装備、モジュールに加え、武器系統別の弾薬を落とします。弾薬は近づくと自動回収し、拠点の店で購入できます。チェストは探索1回ごとに約50%の確率で1個出現します。死の街道のボスは初回撃破時にレジェンダリー武器を必ず落とします。武器・防具・モジュールには性能スコアとレア度由来の追加性能数を表示し、コモンは0個、レア度が上がるごとに1個増加、レジェンダリーは固有効果も持ちます。装備レベルも性能へ反映されます。

## 装備と敵

銃は10本所持・2本装備。Q/ホイールは装備中の2本のみ切り替えます。防具50個、拡張モジュール24個まで所持。防具は頭・胴・腕・脚・足の5部位、モジュールは2枠。装備能力は実戦に反映し、装備画面に基礎値と実効値、条件付き効果を表示します。残弾は銃ごとに保持。最低1本の銃と装備中防具は破棄できません。

18種類の兵器: カービン、SMG、長距離ライフル、ポンプ散弾、速射散弾、短銃身散弾、ベルト給弾、ニードル、コイル、跳弾分裂、同位体ドローン、真空崩壊、現代カービン、ポンプ式ブリーチ散弾、リボルバー、ブローバック式、ハンドキャノン、消音付きピストル。プレイヤーの銃は方向別の描き込みを持つ独立2Dレイヤーです。レベル・レア度・個体差があり、3区域は専用レジェンダリー戦利品を持ちます。通常戦利品のレジェンダリー率0.5%、ボス5%。

徘徊屍・装甲屍の予告近接、跳び屍の突進、酸吐き・放射兵・針撃ちの遠距離攻撃、放射旋回体、膨張屍の爆発、再生母体、荒野の巨骸。前作より敵数・攻撃圧力を上げ、制圧回復を15から8へ減らしています。予告を避け、包囲を防ぐことが重要です。

プレイヤーは15部位の2D原画を関節で動かし、武器と頭・胴・腕・脚・靴の装備を独立レイヤーで同期合成します。本体・防具の5原画方向から左右反転を含む8方向を表示し、武器は18種類それぞれ8方向を用意。両手銃の射撃は右肩に銃床を接し、左手で支持します。片手銃（小型SMG、短銃身散弾、新しいハンドガン4種）は右手で持つ専用の低構え・射撃・走行姿勢を使い、左手は自由に動かします。両手銃の胴体と重なる銃床だけ遮蔽。防具V4は布の野戦装備、革ハーネス、錆びた小鋼板、防毒マスク、少量の薬瓶を用い、オリーブ系と紺・赤スカーフ系の2種類です。新規原画は組み込みimagegenで生成し、Assetsへ保存しています。原画とプロンプトの記録はART_GUIDE.mdとDevelopment/Layered*Art.md、ArmorEnemyArt.md、EnemyArtB.md。

敵10種も種類ごとの2D原画へ移行。5原画方向から8方位を表示し、上半身と左右脚を別々に動かします。歩行・待機・攻撃の予告・攻撃・被弾・死亡に姿勢と変形を使い、射撃系の銃は独立レイヤー。キャラクターを3Dで描画せず、背景・拠点人物は従来の描画を維持します。弾は白熱芯・色付き光・煙の軌跡、発射の複数フレア、方向火花・着弾煙を重ねます。

戦闘中の人物・装備とアイテム画像は、強い黒輪郭と細部の墨線、原画の素材別配色を残したトゥーン描画です。装備全体を一色に染める処理は撤回しました。防具5方向と12種の銃8方向を塗り直し、銀鋼・黒鉄・褐色の木や革・オリーブや紺の布・アイボリーの巻布・少面積の赤/橙/青緑の塗装・色付きレンズを別々に描いています。アイコンと実装備は同じ多色原画を使用します。戦闘カメラは以前より約31%人物が大きく見える倍率です。背面の腕は胴体の奥、左向きの支持腕は銃の手前に描き、腰と肘の構えを調整。射撃は低構えから少し上げて覗く姿勢へ。脚幅を一定にし、足の深さと伸長を抑えた前傾走行を使います。正面/背面の遠近表現を半回転で解釈せず、銃の上下反転と過大表示を防ぎます。

敵は原画の腰と太腿を接続点にし、死亡時は被弾方向へよろめく→膝を折る→横へ沈む動きで終盤に消えます。ステージは面の境目と段差の黒線、床のノイズ整理、壁の縁と保守用マーキングで立体を読み取りやすくしています。UIは冷色の暗いカード、明瞭な文字、選択ハイライトと影を使います。

プレイヤー原画には布のしわ、縫い目、革、金属板、ポーチ、防毒面の光学部品、銃の機関部や照準器を描き込みました。移動時は膝の屈曲、足の前後差、肩腰の逆振りと前傾を使います。背景は暖かい主光と冷たい補助光を維持。全周弾は各弾の方向を予告し、再生母体の回復予告は実際の範囲と射線判定に一致します。

## 旧版を戻す

旧0.6の完全保存先: `D:/Unity/NeonVaultArchives/NeonVault-0.6-before-wasteland-20261012`。Assets/ソース/設定/QA/Windows版と144アセットのSHA256を保管しています。旧アート画像は主Assetsにも残しています。

旧版をそのまま遊ぶにはアーカイブの`Windows/NeonVault.exe`。編集するにはアーカイブのAssets・Packages・ProjectSettingsを独立フォルダーへコピーしてUnityで開きます。手順と変更仕様はDevelopment/WASTELAND.md。セーブは削除していません。

## 検証と保存容量

Windows版を`--smoke --qa-output <出力フォルダー>`で起動すると、実プレイヤーの自動動作・描画・装備保存・地形接続・攻撃・ボス・勝利・死亡・再挑戦を検証し、画像とsmoke-result.txtを出力します。通常セーブを変更しません。人物接写・全敵・全銃の2D一覧も保存します。自動検証と手操作の難易度調整・長時間バランス検証は別です。

主ソースはこのフォルダー。Library/Buildsの既存ジャンクションを維持し、統合ビルド・検証・大きなログはDへ置きます。Windows版配布にはBuilds/Windowsの全ファイルが必要です。
