## Layout / 構成

Armor: 6 columns × 6 rows. Top-down rows: helmets, chest armor, paired gauntlets, trousers/kneeguards, paired boots, detachable overlays. Overlay columns: pouch straps, plate fins, hose tank, utility harness, armor band, visor plate. Structural columns for first five rows: smooth shell / flanges / reinforcement ribs / rounded overlapping lobes / exposed cage / stacked plates. Kestrel initial sheet predates fixed structural column vocabulary; it has six distinct designs per slot, but does not follow that vocabulary exactly.

Module: 6 columns × 2 rows. Housings row: rectangular open bay / round open canister / twin open pods / open cage / shield-shaped case / long rail. Cores row: capacitor bank / battery / coil / fluid capsule / flywheel / relay board. Core must be fitted/centered independently when compositing; native generated core size is larger than requested 55% and is not a pixel-perfect mechanical fit for every housing.

## Inspection and limits / 検査と制限

All accepted outputs visually inspected for independent groups and row/column count. Armor sheets are 1254×1254 RGBA; module sheets generally 2172×724 RGBA (final list below records actual dimensions). True generated alpha retained. Requested 15% margins are not exact: silhouettes sometimes approach cell bounds. Runtime must use bounds-aware fitted UVs rather than assume empty 15% margins. Materials communicate six makers; some Ironwake/Cinder pieces have medieval-like full plate cues despite modern/post-apocalyptic request. These are authoring parts, not 1200 separately painted icons. Actual product count/unique combinations must be established by runtime structural recipe and final QA.

Voltarc first attempt merged trouser/boot content and only five rows; rejected. Original retained in generated_images, accepted asset replaced with corrected generation. Initial failed parallel jobs returned permission revoked/401, resumed only missing jobs; no API fallback used.
