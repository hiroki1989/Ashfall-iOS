# Ashfall contiguous overworld

固定seed 741921、181×161セル（398.2×354.2m）。廃墟の市街・住宅街・南部工業地帯、北と西の森林、Redwood Memorial Park、Graywater Riverfront。反復する部屋グラフではなく、広い地面に独立した建物と蛇行する河川を配置する。道路は5本の曲線で、3本の橋を横断路にする。公園は建物を除外し、路肩に余裕を設ける。地形判定はSectorLayoutを移動・射線・AIで共用する。

公開API: new OverworldGeography() / Layout / Camps[7] / Entrances[100] / Chests[36] / RegionName(position,ja)。ミッション入口は全域の乱数候補32点から既存地点と最も離れた候補を逐次選び100点配置する。行列の目印は存在しない。拠点は大きな楕円の7方向へ分散。宝箱は6×6の層へ分散。地形の最初のflood-fillと木の追加時の接続検査で全地点の到達性を守る。各地点は他地点から9m以上離し、周囲3.4mの開放域へ寄せる。

OverworldScenery.Build(root,materials,geography)は既存RuinSurfaceAtlas-v1とRuinedDistrict shaderを再利用。新規bitmapなし。建物は中空の崩れたレンガ/コンクリート前面、樹木は幹と共有sphereの楕円樹冠/枯枝。朽車は道路肩のセルを閉じ、接続性/目的地の安全距離を再確認したCarsリストへ描く。時計塔・給水塔・看板骨組み・信号・消防栓・ガソリン屋根/ポンプ・公園ベンチ・曲線道路白線を追加する。3本の橋、拠点の土色地面を描く。木は専用の非歩行セル上のみ。横倒しの車や幹が見た目だけの障害物になるのを避ける。

55m区画×共有8材質で静的結合し、区画単位のfrustum cullingを利用。各樹木にMonoBehaviour/Collider/Updateを持たせない。生成meshはOverworldMeshLifetimeが所有し、root破棄時にDestroyする。実iOSのMetal/メモリ/熱負荷測定と最終画面検査は統合QAの対象。独自の全ランドマーク模型、地表起伏、昼夜やストリーミングはこの実装範囲外。


自己確認: D:/Unity/AshfallArtValidation/overworld-geography-selfcheck でUnity math等価stubを用いたRelease C#実行。Connected、全143地点のradius3.4安全、地点間9m以上を確認。26454歩行セル、43建物、66木、入口100/拠点7/箱36、生成221ms（Windows .NET、Unity/iOS実測ではない）。

# 探索と帰還の接続

- iOS版 `D:/Unity/Ashfall-iOS` が対象。メニューの「アッシュフォールへ」から開始。初回はボスのアジトで首輪と借金の会話。各拠点の「街へ出る」または北側出口で屋外へ。
- 屋外も通常の移動・照準・射撃・回避・近接・拾得を使用する。M / 全体地図で実地形の地図を開く。マーカーを押して任務内容を確認し、実際に入口へ近づいてE / 調べるで入場する。遠隔入場不可。
- 訪問した7拠点は地図から相互に移動できる。屋外または拠点からだけ使用可。拠点は商人・返済・スキル・図鑑を維持する。
- ミッション成功は入った入口の前へ帰還。退却も入口へ戻り報酬なし。死亡は最後に訪問した拠点へ戻り、所持スクラップは整数で半減。装備を失う処理はない。
- 屋外の敵は近傍に最大8体、各敵にプレイヤーレベル±1（最低1）を割り当てる。遠方75m以上は退役、4秒ごとに補充候補を抽選。拠点の近くには出現させない。屋外の撃破ではフロア制圧・任務進行を行わない。
- 屋外36チェストは装備を地面に出し、個別の開封時点からミッション成功3回で復活。訪問済み拠点・最後の拠点・開封履歴・帰還入口・屋外位置は独立した `Vault.Overworld.v1` に保存する。屋外位置は8秒ごととアプリ休止・終了時に保存。
- `--overworld-review` はセーブを書き換えない自動検証。実機iOSの性能と操作は別途確認する。
