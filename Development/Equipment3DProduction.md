# 装備3D制作の採用条件

対象は銃606商品（通常576＝6メーカー×6銃種×4シリーズ×4派生、レジェンダリー30）と防具500商品。モジュールは3D対象外。進捗数は `py -3 Development/Tools/EquipmentAudit/audit_equipment_3d.py` の商品固有 `mesh.fbx`＋`atlas.png` で数える。初期ウォーデンの承認済みモデルは別枠で維持する。

1. 素体は装備から独立し、添付参照の黒髪・無精ひげ・オリーブ色シャツ・茶色のズボン・革ブーツを常に同じモデルとして使う。
2. 商品ごとの既存イラストを基に、形状を先に独立モデル化する。同じ銃種・メーカーの承認済み構造部品は再利用できるが、絵だけを旧モデルに貼る成果は採用しない。レジェンダリーは個別形状が必要。
3. テクスチャは防具の前後、銃の左右2方向を用いる。透過境界に余白を作らず、必要な範囲まで5%程度拡大する。正面・側面・背面で空白、二重模様、表裏逆転、主要部品の位置ずれがないことを検査する。
4. 装着時は同じ部位の旧造形を非表示にし、裸素体・1部位のみ・混成・一式を戦闘画面とインベントリで確認する。画像と形状が一致しない候補は `ArtSource/.../Candidates` に保持し、`Resources` に登録しない。

この条件を満たす代表素体・銃・防具の結果が得られるまで、全件の機械的な量産や完了報告は行わない。
