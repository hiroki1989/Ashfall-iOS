# Distinct manufacturer equipment revision — 2026-10-19

Source: D:/Unity/Ashfall-iOS. Target catalogs: 500 guns, 500 armor, 200 modules. Named legendary guns/armor are included in these totals (5 of each per manufacturer). Rarity/level/affixes are individual rolled properties, not additional product counts.

Each product references a physical recipe. Gun silhouette is receiver + barrel + stock; armor is slot + shaped cover + accessory; module is housing + core. Manufacturer construction/material families are precision machined ivory/steel (Kestrel), riveted heavy brown steel/copper (Ironwake), navy ceramic/yellow conductor (Voltarc), bone composite/olive/green fluid (Mireline), orange welded salvage/wood (Cinder), blue ballistic laminate/white identification (Aegis). Product recipe drives both painted illustration composition and runtime geometry. Illustrations remain painted bitmap parts, never a 3D inventory render. These are modular assemblies, not 1,200 individually painted whole objects.

Gun part artwork: built-in imagegen, six independent manufacturer prompts. Exact layout: 6 columns × 3 rows. Row 0 slab rifle / wedge pistol / drum shotgun / twin pod heavy / open frame SMG / bullpup precision receivers, without barrel or buttstock. Row 1 plain long / short fat / twin / finned / cage / triple barrels. Row 2 solid / fork / folded / loop / reservoir / brace stocks. Side view facing right, slight upper visibility, realistic proportions, detailed worn steel/cloth/leather, fine dark ink contours and painterly cel shading, true alpha, no characters/text/UI/logo/background. Each manufacturer's materials and mechanical language follow the preceding specification. Originals preserved in Codex generated_images; asset copies in Assets/Resources/Art/DistinctEquipment. Armor/module prompt details are in DistinctArmorModuleArt.md.

Part bounds metadata uses source alpha analysis only, without repainting generated artwork. Normalized bottom-origin UV rectangles are stored row-major in *-bounds.json; this avoids splitting objects at approximate generated grid boundaries. Some generated sheets do not follow equal row heights. Tool: D:/Unity/BuildTools/equipment_part_bounds.py.

Barrel mechanics: long precision/speed at handling cost; short mobility/reload at accuracy cost; twin more projectiles at rate/capacity cost; fins high cadence at impact cost; cage stability at cadence cost; triple broad salvo at handling/accuracy cost. Stocks trade stability/mobility/reload/accuracy/capacity. Manufacturer tradeoffs apply on creation, not save loading. Old saved IDs and rolled stats remain, with deterministic presentation mapping to new recipes.

Known acceptance gaps before final visual review: modular silhouettes require actual framebuffer comparison; armor shoulder/waist/rear coverage may differ from illustration. Legendary signature crests/optics need illustration parity. Do not claim full design fidelity until these are visually resolved. No IPA produced for this revision.
