# Coding / Unity実装

担当候補: Assets/Scripts、Assets/Editor、必要なProjectSettings。実際の編集範囲はPMOの割当を優先。

- プレイヤー・敵、武器、生成、UI、ローカライズ、性能とアセット接続を実装。
- 現在はランタイム生成の2.5D構成。VaultGameはVaultUIとpartial分割。
- SectorLayoutの地形判定を描画・射線・移動・AI・ミニマップで共用する。
- メニュー・武器・通知を両言語に対応。OS日本語フォントのグリフも考慮。
- 正常系だけでなく、入口出口の到達性、壁への突き抜け、敵の追跡などを確認。
- テストの成功を見せるために機能を無効化しない。既存SmokeRunを必要箇所だけ拡張。
- Unityの開いている編集プロジェクトを強制終了しない。自己確認用ビルドはPMOの割当時だけDの検証コピーで行い、統合ビルドはPMOが行う。
